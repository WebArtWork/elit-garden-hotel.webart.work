# Elit Garden Hotel

Односторінковий сайт-візитка для готелю-ресторану **Elit Garden Hotel** у Кам'янці-Подільському (вул. Огієнка, 39/2).

## Зміст сайту

- Головний екран з фото готелю та рейтингом
- Про готель та зручності
- Номери (Standard Double, Superior Double, Suite, Family Suite)
- Ресторан і тераса
- Галерея
- Карта розташування (Google Maps)
- Форма для бронювання

## Технології

Чистий HTML, CSS та JavaScript — без збірки та залежностей. Фотографії підключені з [Pexels](https://www.pexels.com).

## Перегляд локально

Відкрийте `index.html` у браузері, або підніміть простий локальний сервер:

```bash
npx serve .
```
